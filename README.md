# UX Design Portfolio

A dependency-free UX design portfolio website with polished case studies, a
research-led process section, and a dedicated play lab for fun experiments.

## Pages

- `index.html` - landing page, case study cards, detailed case studies,
  process, and contact section.
- `play.html` - playful UX experiments, warm-up prompt generator, and creative
  inspiration board.
- `styles.css` - responsive visual system and layout styles.
- `scripts.js` - mobile navigation, sticky header state, and prompt generator.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static
file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
